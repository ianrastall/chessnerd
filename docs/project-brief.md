# chessnerd: project brief

Working brief · 21 October 2026

## Purpose and priority

Provide chess reference, data browsing, game downloads and focused browser tools.

Priority: important. Ordering within the five important projects remains open.

## Product track

Astro/TypeScript website with related publications.

The site is one product; six archive repositories are publishing subprojects. CTML and FIDE publications are shared dependencies, not automatically site-owned folders.
